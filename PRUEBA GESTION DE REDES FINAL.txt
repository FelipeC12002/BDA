INSTALACION CORREO----------------------------------
1. Actualizar e instalar
   - apt-get update 
   - apt-get install apache2
   - apt-get install php
   - apt-get install libapache2-mod-php
   - apt-get install postfix
2. Configurar Postfix
   - escoger sitio de internet
   - nombre del domino como mail.com (se puede elegir el que se desee)
   - cd /etc/postfix
   - nano main.cf main.cf.res
   - en my hostname reemplazar por correo y añadir correo en mydestination
   - en la ultima linea agregar home_mailbox = Maildir/ç
   - systemctl restart postfix
3. Instalar y configurar courier
   - apt-get install courier-pop
   - en el mensaje elegir no
   - apt-get install courier-imap
4. Instalar gestor de correos (squirrelmail)
   - wget https://sourceforge.net/projects/squirrelmail/files/stable/1.4.22/squirrerlmail-webmail-1.4.22.zip
   - apt-get install unzip
   - unzip squirrelmail-webmail-1.4.22.zip
   - mover la carpeta: 
     mv squirrelmail-webmail-1.4.22 /smoke/www/
   - cd /var/www/
   - chown -R www-data:www-data squirrelmail-webmail-1.4.22/
   - chmod 755 -R squirrelmail-webmail-1.4.22/
   - mv squirrelmail-webmail-1.4.22 mail
   - cd mail/config
   - cp config_default.php config.php
   - nano config.php
   - cntrol w: data_dir
   - cambiar por data_dir = '/var/www/mail/data/';
                 attachment_dir = '/var/www/mail/attach/';
   - cd /var/www/mail/
   - mkdir attach
   - cd config
   - perl conf.pl
   - Elijo command D
     command >> courier
     command >> 1
      command >> 1
       mail.com
     command >> Q
5. Configurar servidor Apache
   - nano /etc/apache2/sites-available/000-default.conf
     DocumentRoot /var/www/mail
   -systemctl restart apache2
6. Agregar usuarios al sistema
   - adduser felipe
7. Instalar mailutils
   - apt-get install mailutils
8. Mandar correos
   - #su felipe
   - mail marcelo@mail.com
     Cntrl D para enviar el correo
   - Ingresar con el usuario destinatario en la interfaz
   - Desde este usuario enviar un correo al primer usuario
